# 🔐 TrustVault - Secure Password Manager

> A Java-based encrypted vault system built with Spring Boot

## 📌 Overview
TrustVault is a secure, local-first password and credential manager. It uses **AES-256 Encryption** to store your sensitive data safely. Built for my Java Major Project.

**GitHub:** https://github.com/VatsalyaGuntupalli/TrustVault

## ✨ Features
- 🔒 **AES-256 Encryption** - Military-grade encryption for all passwords
- 🔑 **Secure Vault** - Store passwords, API keys, notes securely
- ⚡ **Spring Boot** - Fast, modern Java backend
- 💾 **Local Storage** - Your data never leaves your device
- 🛡️ **Decrypted Vault View** - Secure view with decryption

## 🛠️ Tech Stack
- **Language:** Java 21
- **Framework:** Spring Boot 3.x
- **Security:** Javax Crypto (AES), EncryptionUtil
- **Build Tool:** Maven (pom.xml)
- **IDE:** Eclipse / STS
